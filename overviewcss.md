

what is css?
CSS stands fir Cascading Style Sheets

CSS describes how HTML elements/tag are to be displayed on screen, paper, or in other media.

CSS saves a lot of work. It can control the layout of multiple web pages all at once.

External stylesheets are stored in CSS file.

3 types of css

1) inline css
2) Internal css
3) External css
